SAE 1.02 - Comparaison d'Algorithmes

Étude comparative des performances de différents algorithmes de tri et optimisation du calcul du temps dans une application d'horloge numérique.

Description du projet

Ce projet se concentre sur l'analyse comparative des performances de différents algorithmes de tri (sélection, insertion, bulle) et l'optimisation des calculs de temps dans une application d'horloge. L'objectif était de comprendre l'impact des différentes approches algorithmiques sur les performances et d'identifier les meilleures solutions selon les cas d'utilisation.

Aspects techniques

Technologies utilisées

  • Java
  • System.nanoTime() pour le benchmarking
  • Arrays et manipulation de tableaux
  • Scanner pour l'interaction utilisateur

Algorithmes implémentés

  • Tri par sélection
  • Tri à bulles
  • Tri par insertion
  • Calcul du temps (heures/minutes/secondes)
  • Opérations de symétrie sur matrices

Structure du projet

  • Classes de tri (TriUtil, TrieInsertion)
  • Classes d'horloge (HorlogeComparaison, HorlogeSeconde)
  • Classes de manipulation d'images (Symetrie, MiroirImage)
  • Classes de test et benchmarking

Compétences acquises

Analyse algorithmique

Compréhension approfondie des algorithmes de tri et de leur complexité temporelle

Optimisation

Techniques d'optimisation de code et mesure précise des performances

Expérimentation

Mise en place de protocoles de test rigoureux et analyse comparative des résultats

Méthodologie

Le projet a été réalisé en suivant une approche expérimentale :

  1. Analyse préliminaire : Étude des différents algorithmes de tri et méthodes de calcul du temps
  2. Implémentation : Développement des différentes variantes d'algorithmes
  3. Benchmarking : Mesure précise des temps d'exécution avec System.nanoTime()
  4. Comparaison : Analyse des performances avec différents jeux de données (tableaux triés, inversés, quasi-triés)

Résultats

Les expérimentations ont permis de :

  • Comparer les performances des différents algorithmes de tri
  • Identifier les cas optimaux pour chaque algorithme
  • Optimiser le calcul du temps dans l'application d'horloge
  • Démontrer l'impact de la structure des données sur les performances
