3. Projet phare : SAE 2.01 - Application MPM (4 min)
Contexte du projet
Objectif : Développement d'une application Java pour la gestion de projet
Méthode : Implémentation de la Méthode des Potentiels Metra (MPM)
Fonctionnalités : Calcul des dates au plus tôt, au plus tard, et des marges
Technologies utilisées
Langage : Java
Outils : FileReader, ArrayList, Git
Méthodes : Programmation orientée objet
Réalisations concrètes
Lecture de fichiers de données de tâches
Algorithmes de calcul des dates optimales
Gestion des dépendances entre tâches
Interface de visualisation des résultats
Défis rencontrés et solutions
Défi : Complexité de l'algorithme MPM
Solution : Décomposition en étapes simples et tests réguliers
Résultat : Application fonctionnelle et fiable
